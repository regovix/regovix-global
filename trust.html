1. Hosting & infrastructure

Regovix's global platform is a set of independently deployed applications, each with its own database — a genuine security boundary between apps, not just a role permission.

ComponentProviderNotes
Website & applicationsNetlify, Inc.Hosting and serverless functions
Application databasesSupabase (PostgreSQL)One separate project per application
AI processingAnthropic PBCPowers EvidenceIQ's Contradiction Engine, BarrierWatch's ICAM analysis, and other AI-assisted features

2. Encryption & access controls

  • All data in transit is encrypted via HTTPS — there's no option to access Regovix unencrypted
  • Each application enforces row-level security so an organisation can only ever see its own data
  • Role-based access within each application — different users see only what their role permits
  • Passwords are hashed, never stored in plain text

3. AI data handling

Several Regovix applications use Claude AI (Anthropic) for specific features — EvidenceIQ's contradiction detection, BarrierWatch's ICAM classification and corrective-action guardrail check, and SDS extraction in ChemVault.

Anthropic does not train its models on API data by default under standard API terms. We recommend avoiding submitting sensitive personal information into AI-assisted fields where it isn't necessary for the task.

5. Data export & portability

Your data belongs to you. Most Regovix applications include CSV export for tabular records. If you need a full export in a specific format, contact us directly and we'll arrange it.
